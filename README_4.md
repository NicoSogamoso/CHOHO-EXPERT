# Formulario de registro CHOHO

Formulario web alojado en GitHub Pages. Los datos se guardan en Google Sheets a través de Google Apps Script.

- `index.html`: el formulario (frontend). Cambia `URL_SCRIPT` por la URL `/exec` de tu implementación.
- `CNAME`: subdominio propio (registro.chohocolombia.com).

El código del servidor (`Code.gs`) no va en este repositorio: vive en Extensiones → Apps Script de la hoja.
